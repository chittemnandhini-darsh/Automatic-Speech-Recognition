# Automatic-Speech-Recognition
AUTOMATIC SPEECH RECOGNITION SYSTEM – TEXT AND SPEECH ANALYSIS

PROJECT DESCRIPTION:
This project is an Automatic Speech Recognition (ASR) application that converts spoken audio into text and performs text analysis. It identifies sentiment, extracts keywords, counts words and sentences, and converts recognized text into speech.

FEATURES:
1. Speech-to-Text Conversion
2. Audio Upload and Microphone Recording
3. Text Analysis and Word Counting
4. Sentiment Analysis
5. Keyword Extraction
6. Text-to-Speech Conversion
7. Download Transcript as a TXT File
8. Download Generated Speech as an MP3 File

TECHNOLOGIES USED:
- Python
- Google Colab
- Faster-Whisper
- Gradio
- Hugging Face Transformers
- gTTS (Google Text-to-Speech)

REQUIREMENTS:
- Google account
- Internet connection
- Google Colab
- Audio file in WAV or MP3 format

HOW TO RUN:
1. Open Google Colab.
2. Create a new notebook.
3. Paste the application code into a code cell.
4. Run the code and wait for the required libraries and AI models to load.
5. Open the Gradio application link.
6. Upload an audio file or record speech.
7. Click the "Transcribe and Analyze" button.
8. View the recognized text and analysis report.
9. Download the transcript or generated speech if required.

SAMPLE INPUT:
"Hello everyone. Artificial intelligence helps students learn new things and improve their knowledge."

EXPECTED OUTPUT:
- Recognized text
- Detected language
- Audio duration
- Word count
- Character count
- Sentence count
- Sentiment prediction
- Extracted keywords
- Generated speech file (optional)
